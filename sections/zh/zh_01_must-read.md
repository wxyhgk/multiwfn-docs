## !!!!!!!!!! 所有用户必读 !!!!!!!!!!

1. 欢迎在 Multiwfn 英文论坛（http://sobereva.com/wfnbbs）或 Multiwfn 中文论坛（http://bbs.keinsci.com/wfn）发帖，咨询任何关于使用 Multiwfn 的问题！我始终愿意尽我所能为每一位 Multiwfn 用户提供帮助！！！\()/

2. 若想非常快速地了解如何用 Multiwfn 完成最常见的任务，请查看 Multiwfn 程序包中的“Multiwfn quick start.pdf”。

3. 入门的最佳方式是通读第1章、第2章的2.1~2.5节，然后跟着第4章的教程学习。之后若想进一步学习理论背景和 Multiwfn 的细节，再读第2章的2.6~2.8节和第3章。注意，第4章给出的教程和实例只覆盖最重要、最常用的功能，而不是 Multiwfn 的全部功能。

4. Multiwfn 的不同功能需要不同类型的输入文件，请认真阅读2.5节中的说明。

5. 通常 Multiwfn 在交互模式下运行，但 Multiwfn 也可以在命令行模式下运行，编写 shell 脚本让 Multiwfn 批量处理大量输入文件非常方便。详见5.2节和5.3节。

6. 如果不知道如何把 Multiwfn 在命令行窗口中的输出复制到纯文本文件，请查阅5.4节。如果不知道如何增大 Windows 系统命令行窗口的屏幕缓冲区，请查阅5.5节。

7. 当 Multiwfn 调用 Gaussian 时，若屏幕上出现“No executable for file l1.exe”报错，应先设置 Gaussian 环境变量。Windows 版可参考附录1。（注：Multiwfn 的大多数功能不需要在本地安装 Gaussian）

8. 本手册和 Multiwfn 提示信息中所说的“当前文件夹”，是指你启动 Multiwfn 时所在的路径。如果在 Windows 平台下通过双击可执行文件图标启动 Multiwfn，“当前文件夹”就是存放 Multiwfn 可执行文件的文件夹。在命令行模式下，如果你在“D:\study\”目录下启动 Multiwfn，那么“D:\study\”就是“当前目录”。

9. 请经常访问 Multiwfn 网站，并把程序更新到最新版本。Multiwfn 始终处于积极开发中，经常加入有用的新功能，持续修复程序错误并不断提升效率。
