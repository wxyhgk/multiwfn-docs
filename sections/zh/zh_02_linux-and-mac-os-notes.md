## Linux 和 Mac OS 用户必读

1. 如果你是 Multiwfn 新手，强烈建议使用 Windows 版本，因为该版本比其他版本更稳定，图形界面的显示效果最好，而且无需配置系统。

2. 关于如何安装 Linux 版和 Mac OS 版 Multiwfn，请分别参见2.1.2节和2.1.3节。

3. 在图形界面窗口中显示等值面时，透明样式不起作用。但如果选择把图形保存为图像文件，则生成的图形文件中可以正常渲染透明等值面。

4. 不推荐使用 Mac OS 版本，某些功能可能无法正常工作。

## 关于本手册

本手册的内容按以下顺序组织：

第1章 总览（Overview）：简要介绍什么是 Multiwfn 以及 Multiwfn 能做什么。

第2章 通用信息（General information）：介绍 Multiwfn 除具体功能之外的各个方面，如安装方法、使用方法、支持的文件类型等。

第3章 功能（Functions）：详细介绍 Multiwfn 的全部功能及相关理论。

第4章 教程与实例（Tutorials and examples）：提供大量实用例子，帮助用户使用 Multiwfn 并理解各种分析方法的价值。其中4.A节包含一些进阶教程、重要综述和专题内容。

第5章 技巧（Skills）：介绍使用 Multiwfn 的一些实用技巧。附录（Appendix）

一般来说，本手册通篇用斜体表示输入的命令、期刊名和文件名。非常重要的内容用红色或加粗标出。

你可以直接在 PDF 阅读器的书签窗口中选择相应条目，跳转到指定章节。

本手册的目的不仅是帮助用户使用 Multiwfn，还介绍相关理论。希望每一位量子化学工作者都能从本手册中受益。

尽管我已尽量把本手册写得对初学者友好，但有些专题要求读者具备量子化学基础知识。如果读者认真读过 Ira. Levine 所著的《Quantum Chemistry 7ed》，在通读整本手册时将不会遇到任何困难。
