# **5.6 快速将文件载入 Multiwfn**

也许有时你会觉得输入输入文件的路径很麻烦，尤其当路径很长的时候。下面我提供一些技巧，可以让这一步变得容易得多。

如果你想快速将一个文件载入 Multiwfn 而无需输入其路径，可以先启动 Multiwfn，然后把该文件的图标直接拖入 Multiwfn 的命令行窗口。

在 Windows 平台上，还有一种更简单的方法：直接把文件拖到 *Multiwfn.exe* 的图标上，该文件就会被自动载入 Multiwfn。注意在这种情况下，“当前文件夹”就是输入文件所在的位置。

如果直接输入字母 *o*，上次载入的文件会被再次载入，其路径被记录为 *settings.ini* 文件中的 "lastfile" 变量。

假设你上次载入的文件是 *C:\sob\lover\K-ON\Mio.wfn*，而这次你想载入 *C:\sob\lover\K-ON\Azusa.wfn*，你只需输入 *?azusa.wfn*，即上次涉及的文件夹路径可以用一个问号来代替。
