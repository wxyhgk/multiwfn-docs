# 主功能2：拓扑分析

功能概述：拓扑分析模块适用于 Multiwfn 支持的任何光滑实空间函数（电子密度、拉普拉斯、轨道波函数、自旋密度、ELF、LOL、ESP 等），默认分析电子密度，经选项 `-11` 可切换（切换后先前拓扑结果被清除）。临界点按 Hessian 负本征值个数分为 $(3,-3)$（NCP/极大）、$(3,-1)$（BCP/二阶鞍点）、$(3,+1)$（RCP/一阶鞍点）、$(3,+3)$（CCP/极小）。默认 Newton 法搜索，可配多种起始点模式；找到后用 Poincaré-Hopf 关系 $n_{(3,-3)}-n_{(3,-1)}+n_{(3,+1)}-n_{(3,+3)}=1$（孤立）/$=0$（周期）校验是否找全。之后可生成拓扑路径（键径等）、盆间表面，并可视化、查性质、管理与导出，还可算 Shannon 芳香性指数与 RCP 垂直曲率。

## 子功能/选项：AIM 拓扑分析——找 CP、校验、生成键径（2-吡哆醇 2-氨基吡啶实例）

说明：先用模式 2（核位置，找 $(3,-3)$）+ 模式 3（原子对中点，找 $(3,-1)$）搜全 CP，用选项 0 可视化并校验 Poincaré-Hopf 关系，再用选项 8 生成拓扑路径（键径），选项 0 复看。品红/橙/黄小球分别对应 $(3,-3)$/$(3,-1)$/$(3,+1)$，棕色线为键径；命令行给出每 BCP 相连两原子。CP 标号颜色经 `CP labelling settings` → `Set label color` 改，只标特定 CP 用 `Labelling only one CP` 输入编号（空输入则显示全部）。

菜单路径：主菜单 → `2`（拓扑分析）→ `2` → `3` → `0`（可视化）→ `8`（生成拓扑路径）

输入要求：含电子密度等实空间函数的波函数文件（`.wfn`/`.fch`）。

操作步骤（原始格式）：

```text
examples\2-pyridoxine_2-aminopyridine.wfn  // Assume that the input file is in a subdirectory of current directory, we can only input relative path rather than entire absolute path
2  // Topology analysis
```

```text
2  // Use nuclear positions as initial guesses, generally used to search (3,-3) CPs
3  // Use midpoint of each atomic pair in turn as initial guesses. Generally all (3,-1) CPs could be found, some (3,+1) or (3,+3) may also be found at the same time
```

搜完输入 `0`，输出末尾给出每类 CP 数目（原始格式）：

```text
(3,-3):    25,   (3,-1):    27,   (3,+1):     3,   (3,+3):     0
  25  -   27  +    3  -    0  =   1
```

第二行满足 Poincaré-Hopf 关系，意味着 CP 可能已找全。点 GUI 右上角 `RETURN` 后输入 `8` 生成拓扑路径，再选 `0` 查看。

产出：CP 位置/类型汇总、分子图（键径）、每 BCP 相连原子；N–H···O（CP 53）与 N–H···N（CP 38）氢键 BCP 被定位。

来源链接：[3.14](sec-3-14-topology-analysis.md) · [4.2.1](sec-4-2-topology-analysis.md)

## 子功能/选项：搜索模式 1–6（给定起点/核/原子对中点/三角中心/锥体中心/球内批点）

说明：模式 1 从给定起点搜（直接输坐标，或输两原子序号取中点，或提供 `.pdb`/`.pqr` 依次作起点，或提供 `.txt` 每行一以 Bohr 为单位的 `X Y Z` 起点）；模式 2 依次用核位置作起点（最适找 $\rho$ 的 $(3,-3)$ 及 ELF/LOL/拉普拉斯内层 $(3,-3)$）；模式 3 依次用原子对中点（最适找 $(3,-1)$）；模式 4 用三原子三角中心（找 $(3,+1)$）；模式 5 用四原子锥体中心（补找 $(3,+3)$，组合多更耗时；周期体系模式 3 循环实际+镜像原子，模式 4/5 只循环实际原子）；模式 6 在球内随机撒点（先设球心/半径/点数再选 0 开始；选 `-1` 则每原子中心依次作球心，$n$ 原子、每球 $m$ 点则约 $n \times m$ 个初猜；选 `-2` 则输入原子序号以其核为球心）。**ELF、LOL、拉普拉斯强烈建议用模式 6 选项 `-1` 反复搜多次**；每次撒点位置不同，序号也可能不同。

菜单路径：主功能 `2` → `1` / `2` / `3` / `4` / `5` / `6`

输入要求：GTFs + 原子坐标；LOL/ELF/ESP 等先经 `-11` 切换函数。

操作步骤（原始格式）：

```text
1.2 3.10 -0.4
0.477 5.2 5.92
-3.26 3.3 0.5
...
```

上为模式 1 外部 `.txt` 起点文件格式（每行一 Bohr 坐标，格式自由）。模式 6 下：

```text
6  // 从球内一批点搜索
-1  // 每个原子中心依次作球心
0   // 开始搜索
```

产出：新找到的 CP 并入列表；复杂函数需多次撒点补找。

来源链接：[3.14.2](sec-3-14-topology-analysis.md)

## 子功能/选项：临界点搜索参数（-1）与搜索算法（-1 → 12）

说明：默认参数适合多数体系，特殊情形经 `-1` 调整：1 最大迭代数；2 步长缩放（默认 1.0，如 `uracil.wfn` 的 N6–H12 BCP 须降到 0.5 才找得到）；3/4 梯度范数/位移收敛判据（模式 2 暂移梯度模判据，因重原子核处密度峰太尖锐难收敛）；5 CP 间最小距离（小于此值视为重复丢弃）；6 vdW 截断（原子对距离长于 vdW 和乘该值则跳过，模式 3/4/5 省成本）；7 打印搜索细节（仅串行）；8 Hessian 奇异判据（行列式绝对值低于此值终止，过大漏点、过小数值不稳）；9 只保留函数值在指定范围的 CP（如只留低密度弱作用区）；10 限定搜索原子（方式 1 只在片段内搜；方式 2 在两片段之间搜，组合不全落在同一片段，适于分子间 CP；模式 2 下两方式无区别）；11 信赖半径（位移模大于此值则缩放，如设 0.1 Bohr 更稳）；12 搜索算法（默认 Newton；BB 为类牛顿的最速下降变体，不依赖 Hessian，Newton 失败时试；SA/SD 只找 $(3,-3)$/$(3,+3)$，适于只关心极大/极小、行为差或极值区极窄的函数，用微迭代沿梯度正/负向试探，步幅失败则缩至 40% 重试）。

菜单路径：主功能 `2` → `-1`（设临界点搜索参数）→ 子选项 `1`–`12`

输入要求：同上。

操作步骤（原始格式）：

```text
-1  // 设置临界点搜索参数
2   // 步长缩放因子
0.5
```

产出：参数更新后重搜可找回遗漏 CP；局域/片段间限定搜索大幅降成本。

来源链接：[3.14.2](sec-3-14-topology-analysis.md)

## 子功能/选项：生成拓扑路径（8/9）与路径参数（-2）

说明：选项 8 生成连 $(3,-3)$–$(3,-1)$ 的路径（BCP 沿 Hessian 正本征值本征向量正反位移后沿梯度上坡至 $(3,-3)$，即键径）；选项 9 生成连 $(3,+1)$–$(3,+3)$ 的路径（沿负本征值方向位移后下坡）。路径为曲线上均匀点集。`-2` 可调：1 路径最大点数（超数未遇 CP 则丢弃，长路径须增大）；2 步长（相邻点间隔，大曲率路径默认步长失败时减小；最大长度不超过 $m \times n$）；3 距任一 CP 小于此值即视为相连停止。

菜单路径：主功能 `2` → `8` / `9`（生成路径）；→ `-2`（设路径生成参数）

输入要求：已完成 CP 搜索。

操作步骤（原始格式）：

```text
8  // 生成连接 (3,-3) 和 (3,-1) 的路径（键径）
9  // 生成连接 (3,+1) 和 (3,+3) 的路径
-2 // 设置路径生成参数
```

产出：键径/拓扑路径；分子图；路径点集供后续可视化与沿路径绘性质曲线。

来源链接：[3.14.3](sec-3-14-topology-analysis.md)

## 子功能/选项：生成/删除/查看盆间表面（10）与表面参数（-3）

说明：IBS 为从 $(3,-1)$ 发出的一束路径，把空间切分为各 $(3,-3)$ 流域。须先找全 CP 且至少有一个 $(3,-1)$。输入 `15` 生成对应序号 CP 的 IBS，`-15` 删除，`0` 生成全部（无显示时）或删除全部（已显示时），`l` 列已生成表，`o 4` 把源自 CP 4 的全部路径坐标存 `surpath.txt`，`q` 返回。`-3` 可调每面路径数与步长（路径多/步长小更平滑；面积正比于步长×每路径点数；改参数后已生成面丢失）。`settings.ini` 的 `isurfstyle` 切换描绘方式（1 路径束；2 实心面，默认；3 少用）。

菜单路径：主功能 `2` → `10`（加/删 IBS）；→ `-3`（设 IBS 生成参数）

输入要求：已搜出 $(3,-1)$ 的拓扑结果。

操作步骤（原始格式）：

```text
53  // Generate the IBS corresponding to the (3,-1) CP with index of 33, the same as below. You may need to wait a few seconds for each generation of IBS
38
37
q  // Return
```

产出：IBS 显示于 GUI；可经选项 0 可视化（如二聚体 CP 53/38/37 对应三张 IBS）。

## 子功能/选项：可视化（0）、查 CP 处性质（7）、测几何（-9）、管理 CP（-4）/路径（-5）

说明：`0` 弹 GUI 控制各类 CP/路径/IBS/结构/标签显示，命令行打印汇总并校验 Poincaré-Hopf 关系；电子密度分析还给出 NCP–原子对应与每 BCP 相连两原子。`7` 给出指定/全部 CP 处全部实空间函数值与所选函数梯度/Hessian（ESP 最贵，不需要设 `ishowptESP=0`；后加 `d` 可分解该 CP 处选定函数为轨道贡献）。`-9` 测原子/CP 间距离夹角二面角（如 `c30 a25` 测 CP30–H25 距离得 5.877601 Å；`a14 a13 a12` 测角得 120.297432 度；`q` 返回）。`-4` 打印/增删/导出 CP：子选项 2 按类型/序号范围/距片段距离/密度范围删点，子选项 4 存 `CPs.txt`，子选项 5 从同格式文件载入（清空当前），子选项 6 导出 `.pdb`（C/N/O/F 分别对应 $(3,-3)$/$(3,-1)$/$(3,+1)$/$(3,+3)$）。`-5` 管理路径：子选项 1/2 打印摘要/指定路径坐标，4 导出 `paths.txt`，5 导入同格式，6 导出 pdb，7 沿选定路径绘实空间函数曲线（`Dist.`/`Value` 两列可供 Origin 重绘），3 手动删路径，8 只保留两片段间键径（及相应 BCP）删其余。

## 子功能/选项：切换被分析函数（-11）与各类函数拓扑（ELF/LOL/ESP/vdW/IRI/RDG）

说明：`-11` 切换被分析实空间函数（电子密度/ELF/LOL/拉普拉斯/ESP 等；一旦切换先前结果清空）。LOL 取 10、ELF 取 9、ESP 取 12、vdW 势取 25、IRI 取 24 后，用模式 6 球内撒点（`-1` 每原子球心）反复搜；找 ELF/LOL 极大改用 `-1` → `12` → `3` 最速上升算法。ESP 狭窄谷极小用“盆分析定位 + 拓扑精修”联用；vdW/IRI 极小进入即自动切最速下降（Newton 难收敛）。选项 7 查看极小处 ESP/vdW/IRI 值；IRI 结果可转主功能 4 画平面图对照。

菜单路径：主功能 `2` → `-11`（选实空间函数：`10` LOL / `9` ELF / `12` ESP / `25` vdW 势 / `24` IRI）→ `6`（球内撒点）/ `2`（核位置）→ `8`（生成拓扑路径）

输入要求：`.wfn`/`.fch`（vdW 势仅需 `.xyz` 等几何文件）。

操作步骤（原始格式）：

```text
-11  // 选实空间函数，10 为 LOL、9 为 ELF、12 为 ESP

-1
```

ESP 极小专找（原始格式）：`vmin`（最速下降专找极小）与 `6` 联用；vdW/IRI 进入即自动切最速下降。

产出：LOL/ELF 极大、ESP/vdW/IRI 极小 CP 集；选项 7 给出极小处函数值。

## 子功能/选项：芳香性指数（20 Shannon / 21 RCP 垂直曲率）

说明：实空间函数须为电子密度时 `20`/`21` 可见。`20` 算 Shannon 指数 $SA=\ln(N)-\sum_i^N(-p_i\ln p_i)$，$p_i=\rho(r_{\mathrm{BCP}_i})/\sum_i\rho(r_{\mathrm{BCP}_i})$，依次输入环 BCP 个数与序号；SA 越小越芳香，0.003–0.005 为芳香/反芳香分界。`21` 算 RCP 处垂直环平面密度曲率（越负越芳香）：输入 RCP 序号（或直接输点坐标），选模式 2，再输入拟合平面的三原子序号；若环严格垂直笛卡尔轴（如位于 XY 平面），该曲率即 Hessian ZZ 分量，可直接用选项 7 读取。

菜单路径：主功能 `2`（实空间函数须为电子密度）→ `20`（Shannon）/ `21`（RCP 垂直曲率）

输入要求：已搜出环 BCP/RCP 的电子密度拓扑结果。

操作步骤（原始格式）：

```text
20  // Calculate Shannon aromaticity index
44,42,32,29,31,40
21  // Calculate gradient and curvature of electron density along a given direction
36
2
15,13,17
```

上例氨基吡啶 SA=0.000812（2-吡哆醇 0.000865），故前者芳香性略强；RCP 曲率氨基吡啶 $-0.0187$ a.u. vs 2-吡哆醇 $-0.0164$ a.u.，结论一致。

产出：SA 指数；RCP 垂直曲率。

来源链接：[3.14.6](sec-3-14-topology-analysis.md) · [4.2.1](sec-4-2-topology-analysis.md)
