# 主功能13：处理格点数据

功能概述：主功能13 对内存中的当前格点数据（启动时由 .cub/.grd/CHGCAR 载入，或由主功能5 等生成）做可视化、提取、运算与变换。可将等值面可视化、导出 cube、提取全量/平面/任意平面/数值范围内的数据点、做 22 种格点运算、映射另一 cube 值到等值面、屏蔽片段内外区域、替换与缩放数值、统计与积分曲线、盒内平移与周期复制。涉及另一格点文件时，其原点、平移矢量与各维度格点数必须与内存格点完全一致。

## 子功能：可视化与导出（选项 -2、0、1）

说明：-2 在图形窗口检查等值面（验证运算后格点有效性）；0 连同原子信息导出 cube；1 把全量 X/Y/Z（Å）与数值写 output.txt。

菜单路径：主功能13 → -2（可视化等值面）→ 0（导出 cube）→ 1（输出全部数据点）

输入要求：内存格点数据或 .cub/.grd/CHGCAR。

操作步骤：进入主功能13 后直接选 -2、0 或 1，按提示确认即可；选项 1 输出当前文件夹 output.txt，前三列为 X、Y、Z（Å），最后一列为数据值。

产出：图形窗口等值面；cube 文件；output.txt 全量数据。

来源：[3.16.0 可视化等值面](../sec-3-16-processing-grid-data.md)、[3.16.1 导出 cube](../sec-3-16-processing-grid-data.md)、[3.16.2 输出全部数据点](../sec-3-16-processing-grid-data.md)

## 子功能：提取平面与数值范围内数据（选项 2～10）

说明：2/3/4 输出最接近输入 Z/X/Y 的 XY/YZ/XZ 平面；5/6/7 对 Z/X/Y 范围内多平面平均后输出；8/9 输入三原子或三点定义任意平面＋容差（可投影到 XY）；10 只输出值落在 [下限,上限] 的点（上下限相等时取 ±3% 窄带）。提取平面数据不做插值，格点稀疏时斜面数据点稀。

菜单路径：主功能13 → 2/3/4（XY/YZ/XZ 平面）→ 5/6/7（范围内平均平面）→ 8/9（三原子/三点定面）→ 10（数值范围筛选）

输入要求：内存格点数据（可由主功能5 算好后 0 返回，或载入 .cub）。

操作步骤（原始格式，Z=28～32 Å 平均平面）：

```text
dens.cub  // A cube file generated by Multiwfn or by some external programs, since cube file is generally large, it is not provided in "example" folder. You can also use the grid data generated internally by Multiwfn instead, that is use main function 5 to calculate grid data first and then choose 0 to return to main menu (the just generated grid data is present in memory)
13  // Process grid data
5  // Extract average plane data
28,32  // Range of Z (in Å)
```

操作步骤（原始格式，三原子定义斜面）：

```text
dens.cub
13  // Process grid data
8  // Output data in a plane by specifying three atom indices. This function is commonly used to extract a tilted plane, if the plane is parallel to XY, YZ or XZ, you should use functions 1, 2 or 3 instead, respectively
0  // Use automatically determined tolerance distance. If vertical distance between any point and the plane you defined is smaller than tolerance distance, then the point will be outputted.
1  // Project the data points in the plane you defined to XY plane, so that you can directly import the outputted file to plotting software to draw plane graphs
```

产出：output.txt（坐标＋数值），可导入 Sigmaplot 等画平面图。

来源：[3.16.3～3.16.6](../sec-3-16-processing-grid-data.md)、[4.13.1 提取平面内数据点](../sec-4-13-process-grid-data.md)

## 子功能：格点数据运算（选项 11、12）

说明：选项 11 做 22 种运算（加减乘除常数/格点、乘方、log/exp、绝对值、$A^2\pm B^2$、平均、加权、乘坐标变量、min 等），就地更新格点；选项 12 按等值±百分比偏差取面点，把另一同格点设置 cube 的数值连同坐标输出（如 vdW 面 ESP）。

菜单路径：主功能13 → 11（格点计算，选 1～22 子操作）→ 12（映射另一 cube 值到等值面：输入等值 p、百分比偏差 k、另一 cube 路径）

输入要求：内存格点＋可选第二格点文件（格点设置须一致）；选项 12 需电子密度格点＋同设置的 ESP cube。

操作步骤（原始格式，cube 相减）：

```text
A.cub  // Load the first cube file into memory
13  // Process grid data
11  // Grid data calculation
4  // Subtract the grid data in memory by another grid data
B.cub  // The cube file containing another grid data. Notice that this cube file must have identical grid setting as the first cube file
```

操作步骤（原始格式，双轨道密度加和）：

```text
MO1.cub
13  // Process grid data
11  // Grid data calculation
10  // Perform A^2+B^2=C operation, where A is present grid data (MO1.cub), B is another cube file (MO2.cub), C is the new grid data
MO2.cub  // Load another cube file
```

```text
0  // Output the updated grid data
totdes.cub  // Filename of the new cube file, which contains total electron density of the two orbitals
```

操作步骤（原始格式，电子密度交叠 min，甲烷二聚体例）：

```text
density1.cub
13  // Process grid data
11  // Mathematical operation on grid data
21  // Take min(rho(1),rho(2))
density2.cub
0  // Export resulting grid data
overlap.cub
```

产出：内存格点更新为运算结果，可 -2 预览、0 导出 cube；选项 12 输出 output.txt（面点坐标＋另一文件数值）。

来源：[3.16.7 格点计算](../sec-3-16-processing-grid-data.md)、[3.16.8 映射到等值面](../sec-3-16-processing-grid-data.md)、[4.13.2 数学运算](../sec-4-13-process-grid-data.md)、[4.13.7 电子密度交叠](../sec-4-13-process-grid-data.md)

## 子功能：屏蔽与替换数值（选项 13、14、15、16）

说明：选项 13 把片段缩放 vdW 球之外（缩放为负则为之内）的格点置为期望值；选项 14 只保留两片段缩放 vdW 区叠加区；选项 15 把落在 [下限,上限] 的值统一设为期望值；选项 16 超界截断后线性映射旧区间到新区间。

菜单路径：主功能13 → 13（vdW 缩放因子 → 期望值 → 片段定义）→ 14（vdW 倍数 → 填充值 → 两片段）→ 15（下限、上限、期望值）→ 16（原范围 → 新范围）

输入要求：内存格点数据；片段可直接输原子序号（如 3,5,1-15,20）或原子列表文件（首行为原子数）。

操作步骤（原始格式，只留右侧苯酚等值面）：

```text
examples\phenoldimer.wfn
5  // Calculate grid data
1  // Electron density
2  // Medium-quality grid
-1  // Visualize isosurface
```

```text
0  // Return to main menu
13  // Process grid data
13  // Set value of the grid points that far away from / close to some atoms
-0.7  // That means we will set the value of the grid points inside 0.7 times of vdW radius of the atoms. If input 0.7, then the value of the grid points outside 0.7 times of the vdW radius will be set
0  // Set the value to 0
2  // Defining mode. 2 means inputting atomic indices by hand (if choose 1, external file containing atomic index list will be used to define fragment, see Section 3.16.9 for the format or the next example)
1-13  // Range of atomic indices of the left phenol
```

操作步骤（原始格式，只留两链交叠区，RDG 例）：

```text
RDG.cub  // The cube file of reduced density gradient corresponding to the graph above
13  // Process grid data
14  // Set value of the grid points outside overlap region of the scaled vdW regions of the two fragments
1.8  // The value for scaling vdW radius. In your practical studies, you may need to try this value many times to find a proper value
1000  // Set value of those grid points to 1000, this value is large enough
1  // Defining mode, 1 means using external file to define the fragment
atmlist1.txt  // The name of the atom list file for chain 1
atmlist2.txt  // The name of the atom list file for chain 2
```

操作步骤（原始格式，ELF 0–1 缩放到 0–65535）：

```text
0  // Return to main menu from post-processing interface of grid data calculation
13  // Process grid data
16  // Scale data range
0,1  // Original data range
0,65535  // The range after scaling. Please read Section 3.16.12 for the detail of scaling algorithm.
```

产出：更新后的格点（选项 -2 预览等值面确认；NCI 分子间区可视化常用）。

来源：[3.16.9～3.16.12](../sec-3-16-processing-grid-data.md)、[4.13.3 缩放数值范围](../sec-4-13-process-grid-data.md)、[4.13.4 筛除局域区域等值面](../sec-4-13-process-grid-data.md)

## 子功能：格点统计（选项 17）

说明：输出限制区内最小/最大/均值/RMS/体积/积分与正/负/总重心；选 1 为全点统计，选 2 可限数值范围与球/柱/矩形空间区域；选 y 导出参与格点 grid.xyz 在 VMD 核对区域。

菜单路径：主功能13 → 17 → 1（全部点）/2（特定空间数值范围：数值范围 → 球形/柱形/矩形 → 参数）

输入要求：内存格点数据（如主功能5 算好的轨道/密度格点）。

操作步骤（原始格式，苯酚 MO10 重心）：

```text
examples/phenol.wfn
5  // Calculate grid data
4  // Choose orbital wavefunction
10  // The 10th orbital
2  // Medium-quality grid. Finer quality of grid will give more accurate barycenter positions
0  // Return back to main menu
```

```text
13  // Process grid data
17  // Show statistic data
1  // Select all points
```

绝对值总重心（原始格式，总积分为零的轨道用）：

```text
11  // Grid data calculation
13  // Get absolute value
17  // Show statistic data
1  // Select all points
```

圆柱区域内积分电子密度（原始格式，乙炔 C–C 键例）：主功能5 算好电子密度后 0 返回 → 主功能13 → 17 → 2 → 2（圆柱）→ 两端点坐标 → 半径。

产出：区域内最值、体积、正负积分、重心坐标；总积分为零的轨道应看绝对值重心。

来源：[3.16.13 统计数据](../sec-3-16-processing-grid-data.md)、[4.13.5 分子轨道重心](../sec-4-13-process-grid-data.md)、[4.13.8 圆柱区域积分](../sec-4-13-process-grid-data.md)

## 子功能：积分曲线与平面平均曲线（选项 18）

说明：沿 X/Y/Z 方向求积分曲线 $I$、局域积分曲线 $I_L$ 与平面平均曲线 $p_{\mathrm{avg}}$；被积为电子密度差时积分曲线即电荷位移曲线（CDC），中点最小值即半分子得失电子数。研究方向须满足正交条件（沿 X 则第一平移矢量平行 X、另两平行 YZ 平面，余类推）。

菜单路径：主功能13 → 18 → X/Y/Z 方向 → 下限与上限（回车取全范围）→ 选项 2（局域积分曲线）/选项 1（积分/CDC 曲线）/选项 11（给定位置曲线值）

输入要求：内存格点数据（CDC 需先算好密度差格点，如 field 与无 field 两套 .wfn 相减）。

操作步骤（原始格式，外电场下聚炔 CDC，先算密度差）：

```text
examples\polyyne_field.wfn
5  // Calculate grid data
0  // Custom operation
1
-,examples\polyyne.wfn  //Subtract the property of polyyne.wfn from polyyne_field.wfn
1  // Electron density
2  // Medium-quality grid
```

```text
0  // Return to main menu
13  // Process grid data
18  // Calculate and plot integral curve
Z  // The curve will be plotted in Z direction
[Press ENTER button]  // Select the entire range
```

产出：曲线图与极值位置数值，可导出曲线数据文本；局域积分曲线峰正负对应密度增减区。

来源：[3.16.14 积分曲线](../sec-3-16-processing-grid-data.md)、[4.13.6 电荷位移曲线](../sec-4-13-process-grid-data.md)

## 子功能：平移与周期复制（选项 19、20）

说明：选项 19 在盒内按三轴分数平移格点（超盒绕回，可选把原子一并绕回），周期体系常用，便于把感兴趣区置于原胞中心；选项 20 沿盒矢量复制 N 次（盒子须与单胞重合），可同时复制原子，得超胞格点与结构。

菜单路径：主功能13 → 19（三轴平移分数 → 是否绕回原子）→ 20（复制方向与次数 → 是否复制原子）

输入要求：内存格点数据（正交/非正交均可；选项 20 要求盒子与单胞重合）。

操作步骤（原始格式，溶剂化电子自旋密度居中）：

```text
13  //Processing grid data
19  //Translate grid data
-0.3  //Translate 30% in the negative direction along the first axis
0.5  //Translate 50% in the positive direction along the second axis
[Press ENTER button]  //Do not translate along the third axis
y  //Wrap atoms that outside the box into the box
```

产出：平移/复制后的格点（选项 -2 预览，-1/0 导出 .cub）。

来源：[3.16.15 平移](../sec-3-16-processing-grid-data.md)、[3.16.16 周期复制](../sec-3-16-processing-grid-data.md)

## 实例条目

- 提取 XY 平均面 / 三原子斜面数据点：主功能13 → 5（输 Z 范围）或 8（三原子定面，选容差与是否投影到 XY）；导出 output.txt。来源：[4.13.1](../sec-4-13-process-grid-data.md)
- 缩放 ELF 0–1 到 0–65535：主功能13 → 16 → 原范围 → 目标范围。来源：[4.13.3](../sec-4-13-process-grid-data.md)
- 只留右单体 / 只留片段交叠区等值面：主功能13 → 13（内外模式 → 设值 → 原子）/ 14（vdW 倍数 → 填充大值 → 两片段）。来源：[4.13.4](../sec-4-13-process-grid-data.md)
- 苯酚 MO10 正负部分与绝对值总重心：主功能5 算轨道格点后 0 返回 → 主功能13 → 17 → 1；绝对值先 11 → 13 再 17。来源：[4.13.5](../sec-4-13-process-grid-data.md)
- 外电场下聚炔电荷转移 CDC：密度差格点 → 主功能13 → 18 → Z 方向 → 选项 2 局域积分 → 选项 1 CDC。来源：[4.13.6](../sec-4-13-process-grid-data.md)
- 甲烷二聚体 min(ρ1,ρ2) 交叠格点：主功能13 → 11 → 21 → 0 导出 overlap.cub（补原子坐标头）。来源：[4.13.7](../sec-4-13-process-grid-data.md)
- 乙炔 C–C 键圆柱区域内积分电子密度：主功能13 → 17 → 2 → 2（圆柱）→ 端点 → 半径。来源：[4.13.8](../sec-4-13-process-grid-data.md)
