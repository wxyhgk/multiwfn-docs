# 主功能19：轨道定域化分析

功能概述：正则分子轨道（CMO）高度离域，定域化分子轨道（LMO）则与化学键、孤对电子等经典概念直接对应。Multiwfn 用 Jacob sweep 算法实现 PM-Mulliken（默认）、PM-Löwdin、PM-Becke 与 Foster-Boys（FB）定域化。输入须含基函数信息（.mwfn/.fch/.molden/.gms），仅适用于 HF/DFT 波函数。定域化后 LMO 导出为 new.fch 并自动载入，可用主功能0观察等值面或主功能8做组成分析；还可算 LMO 能量、LMO 中心（Bq 可视化）与占据 LMO 偶极矩。弥散函数大量存在时不要用默认 PM-Mulliken，改用 PM-Becke 或 FB。

## 定域化占据轨道（选项1）

说明：只定域化占据 MO（无特殊原因只做这个，因为只有占据轨道携带电子结构信息，且虚轨道定域化贵得多、收敛更难）。默认 PM-Mulliken 方法（选项-6 可换，选项10 为 Foster-Boys），默认 Hirshfeld 方法计算 LMO 轨道组成（选项-9 可换）。收敛后打印各 LMO 主要特征，LMO 导出为 new.fch 并自动载入。

菜单路径：主功能19（轨道定域化）→ 选项1（选项-6 选方法，选项-9 选组成方法，选项-5 切换是否定域化芯轨道）

输入要求：含基函数文件（.mwfn/.fch/.molden/.gms，仅限 HF/DFT）。

操作步骤（原始格式，SN2 过渡态例）：

```text
examples\SN2\TS.fch
19  // Orbital localization
1  // Localize occupied orbitals
0  // Visualize orbitals
```

小体系定域化迭代立即收敛并打印所得轨道主要特征，LMO 导出为 *new.fch* 并自动载入；进主功能0可看到强定域特征的轨道等值面。若想降低代价，可选一次 "-5 If also localizing core orbitals" 切为 "No"（价–芯混合一般很弱）；若不想自动载入 new.fch，选一次选项-3 切换状态。

产出：屏幕上的 LMO 轨道组成与主要特征；当前文件夹下的 *new.fch*（自动载入）。

来源：[3.22](sec-3-22-orbital-localization-analysis.md)、[4.19.2](sec-4-19-orbital-localization-analysis.md#4192-分析-sn2-反应中定域分子轨道的变化)

## 同时定域化占据与虚轨道（选项2）

说明：占据与虚轨道分组分别定域化（不允许占–虚混合）。虚轨道收敛更难、耗时更长（虚轨道数常多得多）。

菜单路径：主功能19 → 选项2

输入要求：同上。

操作步骤（原始格式，1,3-丁二烯例）：

```text
examples\butadiene.fch
19  // Orbital localization. By default, Pipek-Mezey localization method based on Mulliken population is used
2  // Perform localization for both occupied and unoccupied MOs
```

定域化收敛后 LMO 导出为 *new.fch* 并自动载入；进主功能0观察，例如涉及 C6-C8 的三个 LMO：前两个占据轨道分别对应 σ 键和 π 键，第三个非占据轨道大致为反 π 键轨道。

产出：屏幕上的 LMO 特征；*new.fch*（自动载入）。

来源：[3.22](sec-3-22-orbital-localization-analysis.md)、[4.19.1](sec-4-19-orbital-localization-analysis.md#4191-用-pipek-mezey-方法定域-13-丁二烯的分子轨道)

## 定域化指定 MO 子集（选项3）

说明：只允许所选 MO 在定域化过程中混合，得到局域区半定域轨道，用于特殊目的（如只看特定区域）。

菜单路径：主功能19 → 选项3

输入要求：同上。

操作步骤（原始格式）：进入主功能 19 后选选项 3，按屏幕提示输入要定域化的 MO 子集编号，只允许这些 MO 混合，其余轨道不变。

产出：所选子集的半定域轨道；*new.fch*（自动载入）。

来源：[3.22](sec-3-22-orbital-localization-analysis.md)

## LMO 能量 / 中心 / 偶极矩（选项-4/-8 专题）

说明：专题1算 LMO 能量（Fock 期望值，需提供 Fock 矩阵或由 MO 重构）；专题2算 LMO 中心并以 Bq 幽灵原子加入体系（坐标入 LMOcen.txt，主功能0自动设为最佳显示）；专题3对占据 LMO 做偶极矩分析（结果入 LMOdip.txt，分单中心/双中心轨道偶极矩）。

菜单路径：主功能19 → 选项-4（LMO 能量）/ 选项-8（LMO 中心＋偶极矩，专题1–3）

输入要求：同上（能量另需 Fock 矩阵：由 MO 重构，或从外部文件/.47 载入）。

操作步骤（原始格式，算 LMO 能量，丁二烯例）：

```text
examples\butadiene.fch
19  // Orbital localization
-4  // Allow Multiwfn to generate and print energy for LMOs
1  // Evaluate energies of the LMOs using the Fock matrix generated by MO energies and coefficients via F=SCEC^-1 relationship
2  // Localize both occupied and unoccupied orbitals
```

计算完成后 LMO 能量按从低到高排序打印，例如最高占据与最低非占据 LMO：

```text
   14   Energy:   -0.2750728 a.u.      -7.4851 eV   Type: A+B   Occ: 2.0
   15   Energy:   -0.2750728 a.u.      -7.4851 eV   Type: A+B   Occ: 2.0
   16   Energy:    0.2185911 a.u.       5.9482 eV   Type: A+B   Occ: 0.0
   17   Energy:    0.2185913 a.u.       5.9482 eV   Type: A+B   Occ: 0.0
```

操作步骤（原始格式，显示 LMO 中心，丁二烯＋FB 例）：

```text
examples\butadiene.fch
19  // Orbital localization
-8  // Switch status of “If calculating center position and dipole moment of LMOs” to “Yes”
-6  // Change localization method
10  // Foster-Boys
1  // Localize occupied orbitals (center position of unoccupied LMOs is generally uninteresting therefore we do not localize unoccupied MOs)
n  // Skip the dipole moment analysis
```

定域化完成、new.fch 自动载入后，计算每个 LMO 中心并以 Bq 原子加入体系；中心坐标与 LMO–Bq 对应关系导出到 *LMOcen.txt*，例如：

```text
 LMO     1 corresponds to Bq    11, X,Y,Z:    1.1372    0.7759   -0.0000 Bohr
 LMO     2 corresponds to Bq    12, X,Y,Z:   -1.1372   -0.7759   -0.0000 Bohr
 LMO     3 corresponds to Bq    13, X,Y,Z:    1.1372    3.3081   -0.0000 Bohr
...[ignored]
```

回主菜单进主功能0即可可视化 LMO 中心（青色小球）与轨道等值面。注意 Bq 原子无基函数，此后不应再做波函数分析。PM 方法的重键 σ/π LMO 中心可能重叠，FB 的香蕉键 LMO 中心位置明显不同。

操作步骤（原始格式，键偶极矩，CH₃NH₂ 例）：

```text
examples\CDA\CH3NH2\CH3NH2.fch
19  // Orbital localization
-8  // Switch status of “If calculating center position and dipole moment of LMOs” to “Yes”
1  // Localize occupied orbitals
y  // Perform dipole moment analysis for the LMOs
```

当前目录生成 *LMOdip.txt*，其中例如：

## 定域化方法选择与 [Re₂Cl₈]²⁻ 四重键表征

说明：PM-Mulliken/Löwdin 快而常用但不兼容大量弥散函数；PM-Becke 稳健但很贵（大体系勿用）；FB 兼容弥散函数但把重键表为香蕉键、不保持 σ–π 分离。2-zeta 加极化基组已足够。把 settings.ini 中 "iprintLMOorder" 设为 1 可按原子/原子对顺序打印 LMO 成分，便于找目标键的 LMO。

菜单路径：主功能19 → 选项-6（选方法）→ 选项1

输入要求：含基函数文件（.fch）。

操作步骤（原始格式）：将 settings.ini 中 "iprintLMOorder" 设为 1 后载入 *examples\Re2Cl82-.fchk* 并对占据轨道定域化，从输出直接辨认 Re–Re 键的四个 LMO：

```text
Almost two-center LMOs: (Sum of two largest contributions > 80.0%)
  57:   7(Cl) 73.8%   2(Re) 22.5%        58:  10(Cl) 73.8%   2(Re) 22.5%
  59:   4(Cl) 73.8%   1(Re) 22.5%        60:   2(Re) 48.1%   1(Re) 48.1%
  61:   8(Cl) 73.8%   2(Re) 22.5%        62:   3(Cl) 73.8%   1(Re) 22.5%
  64:   1(Re) 45.9%   2(Re) 45.9%        66:   6(Cl) 73.8%   1(Re) 22.5%
  67:   9(Cl) 73.8%   2(Re) 22.5%        69:   5(Cl) 73.8%   1(Re) 22.5%
  83:   1(Re) 45.9%   2(Re) 45.9%        84:   2(Re) 43.6%   1(Re) 43.6%
```

进主功能0观察：LMO60 对应 σ 键，LMO64/83 对应 π 键，LMO84 对应 δ 键，支持四重键说法。主功能9 算得 Re–Re Mayer 键级 2.94，再做轨道占据数微扰 Mayer 键级分析可得 σ/π/δ LMO 的相对重要性（σ 0.935、每 π 0.661、δ 0.471）。

产出：LMO 组成表与等值面；Mayer 键级及其轨道微扰分解。

来源：[3.22](sec-3-22-orbital-localization-analysis.md)、[4.19.3](sec-4-19-orbital-localization-analysis.md#4193-表征-re₂cl₈²-阴离子的-re-re-键)
